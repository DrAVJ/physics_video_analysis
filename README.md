# Videoanalys — publicerad sida

**https://dravj.github.io/physics_video_analysis/**

Det här repot innehåller bara den färdigbyggda, minifierade filen som
publiceras här — ingen källkod, inga tester, ingen dokumentation. Den
körbara koden är förstås alltid läsbar för den som öppnar webbläsarens
utvecklarverktyg, men algoritmerna, kommentarerna och testsviten som
förklarar dem finns bara i källkodsrepot.

Källkod och utveckling: [`DrAVJ/videoanalys-src`](https://github.com/DrAVJ/videoanalys-src)
(privat). Uppdatera den här sidan genom att bygga och pusha härifrån —
se det repots README, avsnittet *Publicering*.

Publiceras med **Settings → Pages → Source: Deploy from a branch, Branch:
main / (root)** — ingen Actions-workflow, sidan är redan färdigbyggd.
